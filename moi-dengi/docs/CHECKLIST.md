# Чек-лист перед релизом

Проверено сквозным тестом в браузере (`tests/e2e.js`), юнит-тестами (`npm test`) и глазами на светлой и тёмной теме.

| Пункт | Как проверено |
|---|---|
| Первая трата записывается до требования входа | `tests/e2e.js`: после знакомства сразу открыт «+», запись сохраняется, вход предлагается только после неё и закрывается «Не сейчас» |
| Плюс доступен с любого экрана через таб-бар | Нижнее меню вынесено из экранов и фиксировано; «+» открывает одно окно записи |
| Обязательный платёж создаётся за три тапа | `tests/e2e.js`: «Добавить» → «Аренда» → «Сохранить» (сумма вводится на клавиатуре) |
| Напоминание по умолчанию выключено | `tests/e2e.js` и `tests/recurring.test.js`: для выключенного уведомлений нет |
| Подсказка не появляется в первые 14 дней | `tests/nudges.test.js`: 13-й день тишина, 14-й можно |
| Все пустые экраны с призывом к действию | Главная, История, Аналитика, Цели, Платежи: заголовок «Пока пусто», подсказка и кнопка |
| Тёмная тема проверена на контраст | Текст и подписи 6,3:1 и выше, акцент 6,7:1, кнопки 15:1; «+» (крем на зелёном) выше 4:1 |
| Тост «Вернуть» живёт 5 секунд и больше | `tests/e2e.js`: тост виден через 5 секунд и исчезает к 6,5 секундам (в коде 6000 мс) |
| Нет баннеров и рекламных вставок | В коде и зависимостях нет рекламных SDK и слов «реклама», «партнёр» |
| Нет помесячной подписки ни в каком виде | Только разовая покупка «Фин Навсегда» (`www/js/sub.js`); в окне покупки нет слов про месяц, пробный период и продление |
