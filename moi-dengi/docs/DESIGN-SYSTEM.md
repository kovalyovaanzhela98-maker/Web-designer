# Дизайн-система «Мои деньги»

Полная версия с примерами — `brandbook/brandbook.html` (открывается на телефоне, собирается командой `npm run brandbook`).

**Персонаж.** Фин: пушистый кремовый друг с зелёным листом и длинными ушками. Картинки — `www/img/fin`, список поз — `www/js/mascot.js`.
**Цвет.** Индиго `#2F4AA8` (основной), монета `#F2C230` (акцент), чернила `#1D2433`. Доход зелёный, расход красный. Все токены в `www/tokens.css`, сразу для светлой и тёмной темы.
**Шрифты.** Заголовки и суммы: Wix Madefor Display. Текст интерфейса: Golos Text. Файлы лежат в `www/fonts`.
**Сетка.** Шаг 4 px. Между блоками 12, между разделами 24, по бокам 16. Касание не меньше 44 px.
**Иконка приложения.** Подмигивающий Фин на тёмно-зелёном фоне: `resources/source/app-icon.png`, пересборка `npm run icons`.
**Иконки.** Собственный двухтоновый набор на сетке 24, `www/js/icons.js`. Эмодзи и стандартные наборы не используем.
**Тексты.** На «ты», коротко. Ошибка: что случилось и что делать. Помощник, не «ИИ».

## Как добавить
- Категория: `www/js/categories.js` → иконка в `icons.js` → слова в `parser.js` → проверка в `tests/parser.test.js`.
- Иконка: правила в брендбуке, раздел «Иконки».
- Поза Фина: `POSES` в `mascot.js`.
- Цвет, размер, радиус: только через `tokens.css`.
