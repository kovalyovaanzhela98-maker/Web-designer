# Как включить вход и облако (один раз, ~15 минут, можно с телефона)

Пока файла `android-config/google-services.json` нет, приложение собирается в режиме «без входа»: всё работает, данные лежат только на телефоне. Как только файл появится в репозитории, следующая сборка включит вход (Google или Apple, телефон, почта) и синхронизацию между устройствами. Вход не обязателен: можно записать первую трату и только потом войти.

## 1. Проект Firebase
1. Открой https://console.firebase.google.com, войди своим Google-аккаунтом.
2. «Создать проект» → назови `moi-dengi` → Google Analytics отключи → «Создать».

## 2. Способы входа
Сборка → Authentication → «Начать» → вкладка «Способ входа»:
- **Электронная почта/пароль**: включить (нужна для привязки почты в «Профиле»).
- **Google**: включить, указать свою почту поддержки. Это основной способ входа.
- **Телефон**: включить (по желанию, для привязки номера в «Профиле»). Для настоящих СМС Firebase может потребовать тариф «Blaze» (оплата по факту использования, на личных объёмах обычно 0). Для проверки можно добавить тестовые номера в этом же окне.
- **Apple**: нужен платный аккаунт Apple Developer (99 $ в год). Кнопка включена в `cloud.config.json` (`"apple": true`). Пока Apple не настроен в Firebase, она ответит «Этот способ пока недоступен»; если хочешь скрыть её до настройки, поставь `false`.

## 3. База данных
Сборка → Firestore Database → «Создать базу данных» → режим «production», регион `eur3` (Европа) → «Создать». Затем вкладка «Правила» → вставь содержимое файла `firestore.rules` из этого репозитория → «Опубликовать». Эти правила разрешают каждому видеть только свои данные.

## 4. Подключить Android-приложение
Шестерёнка → «Настройки проекта» → «Ваши приложения» → значок Android:
- Имя пакета: `by.moidengi.app`
- Отпечаток SHA-1: `CE:AA:77:CB:65:B7:4F:34:96:56:0E:CC:0A:DF:90:47:BA:A7:E5:98`
- Нажми «Зарегистрировать» и скачай `google-services.json`.

> Скачивай файл **после** шагов 2 и 4 (Google включён и SHA-1 добавлен). Если скачала раньше, зайди в «Настройки проекта» и скачай его заново.

## 5. Положить файл в репозиторий
На github.com открой репозиторий → папка `moi-dengi/android-config` → «Add file» → «Upload files» → выбери `google-services.json` → «Commit changes» в ту же ветку. Сборка запустится сама, и новый APK появится в разделе Releases.

## Как это устроено
- Данные каждого человека лежат в Firestore: `users/{uid}` (валюта, цели, обязательные платежи, подсказки, праздники) и `users/{uid}/tx/{id}` (операции). Телефон хранит копию и работает без интернета, изменения отправляются при появлении сети.
- Ключ подписи `android-config/debug.keystore` лежит в репозитории специально: у него постоянный SHA-1, а Google-вход привязан именно к нему.
- При первом входе то, что уже было записано на телефоне до аккаунта, не теряется: если в облаке пусто, оно туда загружается; если в аккаунте уже есть данные, записи, цели и платежи объединяются.
