# Фин Навсегда: разовая покупка

Подписки в приложении нет ни в каком виде: ни помесячной, ни годовой, ни пробного периода с автопродлением. Остаётся бесплатный Фин и одна разовая покупка «Фин Навсегда», которая снимает мягкие ограничения. Человеку не нужно ничего отменять и бояться списаний.

## Что бесплатно, что за покупку
Настраивается в `www/js/sub.js`:
- `FREE` — пределы бесплатной версии: до 10 обязательных платежей, 1 активная цель, 1 время напоминания в день;
- `GATES` — тексты окна покупки для каждой функции;
- `PRODUCT` — название, подпись цены и идентификатор товара (`fin_lifetime`).

За покупку: больше десяти платежей, чеки и выписки в «Спросить Фина», больше одной цели, до трёх напоминаний в день и свои дни недели.

## Как сейчас работает
Платёжного провайдера нет, поэтому сборка тестовая: кнопка «Купить навсегда» просто включает доступ, деньги не списываются, на экране так и написано. В Профиле → «Фин Навсегда» тестовый доступ можно выключить.

## Как включить настоящие платежи
1. Нужен аккаунт разработчика Google Play (разовый взнос $25) и платёжный профиль продавца.
2. Приложение нужно собрать в release (AAB, своя подпись) и загрузить в закрытое тестирование: без этого Google Play Billing не отдаёт товары.
3. В Play Console → Монетизация → Продукты → «Разовые продукты» создай товар `fin_lifetime` (разовая покупка, не подписка).
4. Подключи плагин, например `@revenuecat/purchases-capacitor` (проще всего, он же проверяет покупки) или `@capgo/native-purchases`.
5. Назначь провайдера в начале `app.js` или в отдельном файле:
```js
MD.sub.provider = {
  async purchase(productId) { /* оплата → вернуть { ok: true } */ },
  async restore() { /* вернуть { ok: true } или null */ }
};
```
Как только `provider` задан, на экране покупки пропадает пометка про тестовую сборку, а кнопка «Восстановить покупку» появляется.

Для Беларуси учти: платные приложения и покупки в Google Play доступны разработчикам и покупателям из ограниченного списка стран. Проверь свою страну в справке Play Console, при необходимости юридическое лицо можно зарегистрировать в другой стране.
