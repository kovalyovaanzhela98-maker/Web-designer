# Фин

Личный учёт расходов и доходов. Чистые HTML/CSS/JS + Capacitor 7 (Android). Бесплатный, без рекламы, без подписки (одна разовая покупка «Фин Навсегда»). Вход необязателен: Google или Apple, телефон, почта за «Другими способами»; облако на Firebase. Нейросетей нет: помощник и подсказки работают по правилам прямо на телефоне.

- `www/` — приложение: `tokens.css` (токены), `app.css` (компоненты и экраны), `js/` (иконки, персонаж, парсер фраз, обязательные платежи, вход и облако)
- `brandbook/` — брендбук: `brandbook.html` (готовый файл) и исходники
- `docs/FIREBASE.md` — как включить вход и облако
- `docs/SUBSCRIPTION.md` — разовая покупка «Фин Навсегда» и подключение настоящих платежей
- `docs/PAYMENTS.md` — обязательные платежи: как устроены, напоминания, отметки
- `docs/NUDGES.md` — «Фин заметил»: правила подсказок по привычкам
- `docs/ASSISTANT.md` — что умеет помощник и как подключить языковую модель
- `android-native/` — нативный код: виджет, плитка шторки, кнопки на экране блокировки (ставится скриптом `scripts/patch-android.js`)
- `npm run serve` — открыть в браузере (`?mock=1` — с имитацией входа)
- `npm test` — проверка разбора фраз
- `npm run icons` — пересобрать иконку приложения
- `npm run brandbook` — пересобрать брендбук
- APK собирает GitHub Actions (`.github/workflows/build-apk.yml`), готовый файл — в разделе Releases
